# ⚔️ The Threshold — Criador de Fichas de RPG

Um sistema completo, elegante e responsivo de criação de fichas para o RPG medieval de mistério **The Threshold**.

## 📁 Arquivos do Projeto
- `index.html` (Estrutura da página e navegação)
- `styles.css` (Estilos visuais, responsividade e paleta temática)
- `app.js` (Lógica completa, manipulação de atributos, armazenamento local e exportação PNG)

## 🚀 Como publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Faça o upload dos três arquivos (`index.html`, `styles.css`, `app.js`).
3. Vá em **Settings > Pages**, selecione a branch `main` e clique em **Save**.
